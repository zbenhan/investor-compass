# 100篇文章策划计划

## 计划概述
基于 Investor Compass (投知罗盘) 的四大投资门派（价值、技术、宏观、叙事），策划100篇高质量投资知识文章，涵盖理论深度、实战案例、工具方法、风险管理等多个维度。

## 文章分类分布

### 一、价值投资类 (25篇)
1. 价值投资基础理论 (5篇)
   - 价值投资的起源与发展历程
   - 格雷厄姆的证券分析核心思想
   - 巴菲特的投资哲学演变
   - 芒格的"以合理价格买入优秀公司"理念
   - 费雪的成长股投资方法

2. 估值方法与工具 (5篇)
   - DCF现金流折现模型详解
   - PE/PB/PS/PEG估值指标应用
   - ROE/ROIC等盈利能力指标分析
   - 自由现金流计算与应用
   - 企业价值(Enterprise Value)与股权价值

3. 行业与公司分析 (5篇)
   - 如何分析企业护城河
   - 竞争优势的可持续性评估
   - 管理层评估方法
   - 财务报表分析技巧
   - 行业生命周期与投资机会

4. 价值投资实战案例 (5篇)
   - 巴菲特投资可口可乐案例深度分析
   - 巴菲特投资苹果公司案例
   - 巴菲特投资比亚迪案例
   - 价值陷阱识别与规避
   - 价值投资在A股市场的应用

5. 价值投资进阶 (5篇)
   - 价值投资与技术分析的结合
   - 价值投资与宏观周期的配合
   - 价值投资的心理学挑战
   - 价值投资组合管理
   - 价值投资的风险控制

### 二、技术分析类 (25篇)
1. 技术分析基础理论 (5篇)

   - 支撑与阻力位的识别
   - 成交量分析基础
   - 技术分析的有效性探讨

2. 技术指标详解 (5篇)
   - MACD指标实战应用
   - RSI相对强弱指标详解
   - KDJ随机指标应用
   - 布林带(Bollinger Bands)策略
   - 威廉指标(WR)应用

3. 技术形态分析 (5篇)
   - 头肩顶/底形态识别与交易
   - 双顶/双底形态实战
   - 三角形形态（上升、下降、对称）
   - 旗形与楔形形态
   - 杯柄形态(Cup and Handle)

4. 交易策略与系统 (5篇)
   - 趋势跟踪策略详解
   - 均值回归策略应用
   - 突破交易策略
   - 波动率交易策略
   - 量化交易系统构建

5. 技术分析进阶 (5篇)
   - 多时间周期分析
   - 技术分析与基本面结合
   - 技术分析的心理层面
   - 算法交易入门
   - 高频交易基础

### 三、宏观投资类 (25篇)

   - 通货膨胀与通货紧缩
   - 货币政策传导机制
   - 财政政策与经济影响
   - 全球经济联动分析

2. 宏观指标深度解析 (5篇)

3. 央行政策分析 (5篇)

   - 中国央行货币政策
   - 日本央行超宽松政策
   - 央行政策对资产价格的影响

4. 资产配置策略 (5篇)
   - 股债平衡配置
   - 大宗商品投资策略
   - 外汇投资基础

5. 宏观投资实战 (5篇)

   - 全球宏观对冲基金案例
   - 宏观投资的风险管理

1. 叙事投资基础理论 (5篇)
   - 叙事投资心理学基础
   - 市场情绪指标分析
   - 社交媒体与投资叙事
   - 新闻媒体对市场的影响

2. 经典叙事案例 (5篇)
   - 互联网泡沫(1995-2000)深度分析

   - 加密货币叙事周期
   - 新能源汽车叙事

3. 叙事识别方法 (5篇)

   - 叙事强度量化方法
   - 叙事与基本面的匹配度

4. 叙事投资策略 (5篇)

将创建一个计划文件 `100-articles-plan.md`，包含所有100篇文章的详细标题、分类、内容简介和优先级。
