# 上市公司调查报告辅助功能 - 完整实现计划

## 📋 项目概述
为投知罗盘添加上市公司调查报告生成器，支持四大投资门派（价值/基本面、趋势/技术、宏观/周期、信息/叙事）的全维度分析，采用 LocalStorage 本地存储 + 导出/导入备份方案。

## 🎯 核心功能模块

### 1. 报告项目管理器
**功能：**
- 报告列表展示（卡片式布局）
- 新建报告
- 编辑报告
- 删除报告（带确认）
- 搜索和筛选报告
- 报告排序（按时间、名称）

**UI 组件：**
- 报告卡片（显示标题、公司、更新时间、进度）
- 操作按钮（编辑、删除、导出）
- 搜索框
- 新建按钮

### 2. 报告编辑器
**功能：**
- 分步式表单（向导模式）
- 四大投资维度可选填
- 自动保存草稿
- 进度追踪
- 实时预览

**表单结构：**

#### 第1步：基本信息（必填）
- 报告标题
- 公司名称
- 股票代码
- 行业分类（下拉选择）
- 报告日期
- 投资目标（文本框）

#### 第2步：选择分析维度
- 价值/基本面派（复选框）
- 趋势/技术派（复选框）
- 宏观/周期派（复选框）
- 信息/叙事派（复选框）

#### 第3步：价值投资维度（可选）
- 财务指标分析
  - PE、PB、ROE、ROA、毛利率、净利率
  - 营收增长率、利润增长率
  - 现金流分析
- 商业模式分析（文本域）
- 竞争护城河评估（文本域）
- 管理层评估（文本域）
- 估值模型（文本域）
- 安全边际分析（文本域）

#### 第4步：趋势投资维度（可选）
- 技术形态分析（文本域）
- 交易量分析（文本域）
- 趋势线识别（文本域）
- 支撑位/阻力位（文本域）
- 技术指标（文本域）
- 入场/出场信号（文本域）

#### 第5步：宏观投资维度（可选）
- 行业周期位置（下拉选择：复苏/扩张/过热/衰退）
- 政策环境分析（文本域）
- 宏观经济指标影响（文本域）
- 产业链分析（文本域）
- 资产配置建议（文本域）
- 经济周期判断（文本域）

#### 第6步：叙事投资维度（可选）
- 市场情绪分析（文本域）
- 投资故事梳理（文本域）
- 叙事传播路径（文本域）
- 热度评估（文本域）
- 情绪转折点识别（文本域）
- 主题投资关联（文本域）

#### 第7步：综合分析（必填）
- 投资逻辑总结（文本域）
- 风险分析（文本域）
- 投资建议（文本域）
- 后续跟踪计划（文本域）

### 3. 报告预览器
**功能：**
- 实时预览报告内容
- 格式化展示
- 打印预览
- 导出选项

**展示格式：**
- 专业报告布局
- 分章节展示
- 数据可视化（图表）
- 打印优化

### 4. 导出/导入功能
**导出功能：**
- 导出为 PDF（使用 jsPDF + html2canvas）
- 导出为 Word（使用 docx.js）
- 导出为 JSON（备份用）

**导入功能：**
- 从 JSON 文件恢复报告
- 支持批量导入
- 导入冲突处理（询问覆盖/跳过/重命名）

### 5. 自动保存系统
**功能：**
- 每30秒自动保存
- 离开页面时提示保存
- 显示保存状态（已保存/保存中/未保存）
- 保存历史记录（最多保留10个版本）

### 4. 导出功能实现

**PDF 导出**
```javascript
async function exportToPDF(report) {
  const element = document.getElementById('report-preview');
  const canvas = await html2canvas(element);
  const imgData = canvas.toDataURL('image/png');
  const pdf = new jspdf.jsPDF();
  pdf.addImage(imgData, 'PNG', 10, 10, 190, 0);
  pdf.save(`${report.title}.pdf`);
}
```

**Word 导出**
```javascript
function exportToWord(report) {
  const doc = new docx.Document({
    sections: [{
      properties: {},
      children: [
        new docx.Paragraph({
          children: [new docx.TextRun(report.title)]
        }),
        // 添加报告内容
      ]
    }]
  });
  
  docx.Packer.toBlob(doc).then(blob => {
    saveAs(blob, `${report.title}.docx`);
  });
}
```
