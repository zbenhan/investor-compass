I. Revue du marche Tesla 2020

  • Avril-Juin : Le prix de l'action a commence a monter, brisant les 200 dollars
  • Juillet-Aout : Le prix de l'action a accelere a la hausse, brisant les 400 dollars
  • Septembre-Octobre : Le prix de l'action a recule a environ 300 dollars
  • Novembre-Decembre : Le prix de l'action a remonte, brisant les 700 dollars

Plusieurs evenements cles se sont produits en 2020 qui ont pousse le prix de l'action Tesla plus haut :
